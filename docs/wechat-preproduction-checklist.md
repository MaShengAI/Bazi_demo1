# 微信真机预发布验收清单

记录域名、构建版本、提交哈希、测试日期、微信版本、系统版本、设备型号、网络和测试人。至少覆盖一台有刘海/灵动岛的 iPhone、一台主流 Android；所有请求必须是同一 HTTPS 域名，微信调试信息和服务器日志中不得出现 `localhost` 或 DeepSeek 密钥。

## 基线与安全

- [ ] 微信内直接打开 HTTPS 链接，无证书警告、混合内容或循环跳转；HTTP 链接自动跳 HTTPS。
- [ ] 首页、普通排盘、AI 提交和轮询都只访问当前域名的 `/api/v1`。
- [ ] 响应含 CSP、HSTS、`nosniff`、拒绝 iframe 等安全头；页面不能被第三方 iframe 嵌入。
- [ ] 查看前端资源、`version.json`、公开配置与容器 Web/API 环境，均无 DeepSeek 密钥；只有 worker 环境持有它。
- [ ] 用请求响应头的 `X-Request-ID` 能定位 API JSON 日志；AI 提交日志能关联 `job_id`，worker 日志可按同一 `job_id` 检索。

## iPhone 微信

- [ ] 首次进入、刷新和从聊天返回均正常；状态栏、刘海/灵动岛与底部 Home Indicator 不遮挡内容或按钮。
- [ ] 日期时间选择、性别、省市、隐私勾选和提交触控区域足够，页面无横向滚动。
- [ ] 姓名输入弹出软键盘后，当前输入框和提交按钮可见；收起键盘后视口恢复且不留白、不跳位。
- [ ] 页面切到微信聊天/锁屏 30 秒再返回：轮询在后台暂停、前台恢复，不重复创建 AI 任务。
- [ ] AI 运行中关闭页面再从历史/聊天打开：通过本地 `job_id` 恢复进度；刷新后结果仍可恢复。

## Android 微信

- [ ] 不同状态栏/导航栏模式下顶部、底部安全区正常，全面屏手势区域不遮挡操作。
- [ ] 软键盘弹出、切换中文输入法、粘贴姓名、收起键盘时布局稳定，无缩放或横向溢出。
- [ ] 按系统返回键关闭弹窗而不误退出；再次返回页面时状态一致。
- [ ] 切后台 30 秒、系统省电限制后返回：自动恢复轮询，未出现多个并行请求或重复任务。
- [ ] 刷新、杀死微信后重开链接，已提交任务按 `job_id` 恢复；失效任务给出可理解提示。

## 网络恢复

- [ ] 在正常 Wi-Fi 完成普通排盘和一次 AI 任务，结果、请求 ID 和 job ID 一致。
- [ ] 限速到弱网（高延迟/低带宽/少量丢包）：出现等待提示，轮询指数退避，普通排盘不会重复提交。
- [ ] 提交前断网：立即出现离线提示，不产生服务端任务；恢复网络后可以手动继续。
- [ ] AI 轮询中断网 30 秒再恢复：不丢 job ID、不重复创建任务，自动继续并最终显示结果。
- [ ] 请求发送后立刻切断网络：恢复后通过原 job ID 查询；服务端去重保证重复点击不重复调用模型。
- [ ] MySQL 停止时普通 `POST /api/v1/charts` 仍成功，AI 接口明确提示暂不可用；MySQL 恢复后 AI 可继续。
- [ ] worker 停止或 DeepSeek 不可用时普通排盘仍成功，AI 保持 pending/失败可重试；worker 恢复后租约任务继续。

## 缓存、升级与展示

- [ ] 先打开旧版本，再部署新版本：回到前台或等待版本检查后出现更新提醒。
- [ ] 确认刷新后加载新哈希资源；`index.html` 和 `version.json` 未被微信/CDN 长期缓存。
- [ ] 320 px 小屏、系统大字体和长姓名/错误提示下无截断、重叠、横向滚动。
- [ ] 排盘结果长页滚动流畅；展开大运流年后仍可返回原位置。
- [ ] 自定义确认弹窗在软键盘、横竖屏切换和安全区下可操作。

## 通过标准与留证

所有阻断项必须通过；非阻断视觉问题需记录截图、设备、复现步骤和 request/job ID。每个平台至少保留：首页、填写态、普通排盘结果、AI 进行中、AI 完成、离线提示、后台恢复和版本更新八组截图或录屏。服务器侧保留对应时间段的脱敏日志和健康状态快照。
