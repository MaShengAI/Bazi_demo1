# 用户评价

已登录用户可从已完成八个板块的报告底部“写评价”入口评价一次，不提供报告选择器。接受全部1～5星和2～100个可见字符的文字。表单保留评分长条、输入框和可修改的快捷评价；评价页不再展示公开资料说明或二次确认弹窗。点击提交后仅在服务器确认成功时显示“评价成功”；失败保留原文并可重试。页面并发提交锁与服务端唯一约束共同避免重复赠券。

公开资料由服务端从关联报告及账户生成快照：昵称首个字素、头像、性别、每五年年龄段、日主、生肖、八字、出生省份。不会返回完整姓名、出生日期、城市、账户编号或报告编号。请勿在评价文字中填写隐私资料。

评价与50元赠券在同一事务中入库。报告唯一评价约束、用户行锁和赠券来源唯一约束共同防止重复领取；同一内容重试返回原结果。赠券从提交成功起7天有效，与评分及审核无关。关闭购买不会关闭评价。

新提交评价按评分决定初始状态：1～3星待审核，仅本人及管理员可见；4～5星自动通过并进入公开列表，自动审核操作者为system:rating。自动审核记录和赠券在同一事务内提交，失败全部回滚；不会增加用户端审核通知。后台“评价管理”仍可通过或隐藏任何评分，隐藏后重复提交不会重新通过或重复赠券。此规则不批量改动已有评价的审核状态。公开页按提交时间倒序，每页10条。隐藏不撤销赠券。删除关联报告会撤下评价，已发赠券仍保留。
