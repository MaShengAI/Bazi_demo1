# 开放问题

以下事项存在流派或产品语义差异，本版本采用了明确但可版本化的决定：

1. **神煞范围**：仅实现 `docs/shensha-rules.md` 的五类规则。需要产品方提供目标流派及逐项定义后才能扩展。
2. **起运公历日期**：传统360日年龄拆分后，以出生真太阳时进行公历年/月/日加法，月底截断。部分排盘系统会直接按比例天数相加，结果可能相差数日。
3. **正好出生在“节”边界**：上一/下一节按严格早于/晚于选择，避免零岁起运；如果目标流派把当前节当作参照，需要单独升级规则版本。
4. **城市数据授权**：当前392条经纬度来自项目所有者提供的 `longitude_latitude.csv`，文件没有附带许可或出处说明。对外发布前需要补充可核验的数据来源及再分发授权。
5. **新疆时间语义**：当前按官方北京时间 `Asia/Shanghai` 解释新疆出生证明时间。如果未来需要支持民间新疆时间，必须设计明确输入方式，不能根据地点静默切换。
6. **均时差精度**：目前采用 NOAA fractional-year 近似式。如果要求天文秒级精度，应改用经验证的星历算法并升级计算规则版本。
