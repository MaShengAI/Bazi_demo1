# 计算规则 1.0

## 时间流水线

1. 用项目 `location_id` 从内置中国城市表解析省份、城市、经纬度与 IANA timezone ID；范围外地点直接拒绝。
2. 将无偏移的出生证明时间交给 `zoneinfo`。通过 UTC 往返验证 fold 0/1，检测重复时间与不存在时间。
3. `utc_instant` 是出生的真实瞬间。`standard_local_time` 是同一瞬间在不含 DST 的固定标准偏移下的表示，不能再次减 DST。
4. 标准中央经线为 `standard UTC offset hours × 15°`。每一度经差折合4分钟。
5. 均时差使用 NOAA fractional-year 公式：

   `E = 229.18 × (0.000075 + 0.001868 cos γ - 0.032077 sin γ - 0.014615 cos 2γ - 0.040849 sin 2γ)` 分钟。

6. `true solar = standard local + longitude correction + E`。

包括香港、澳门、台湾在内的全部34个省级行政区，统一按北京时间 `Asia/Shanghai` 解释出生证明时间。这是强制产品规则，不采用港澳台各自的历史时区或夏令时。

## 节气边界

节气表由固定版本 `lunar-python` 生成。库输出按固定北京时间 UTC+08:00 解释，再转成 UTC。原始秒级值保留；边界在加载时执行一次 half-up 分钟量化。出生输入本身已经是整分钟，因此起运差值是整数秒且没有中间舍入。

年柱在量化后的立春瞬间切换。月柱只在立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪和小寒切换。到达边界分钟即属于新柱。

## 日时柱

日柱基础值由 `lunar-python 1.4.8` 提供，适配层强制 `EightChar.setSect(1)`。因此真太阳时22:59仍是当天，23:00属于次日。时支以23:00为子初；时干由已经换日后的日干按五鼠遁计算。

## 十神与衍生字段

日干是十神唯一参照。同性/异性结合五行生克产生比肩/劫财、食神/伤官、偏财/正财、七杀/正官、偏印/正印。日柱透干显示“日主”。藏干顺序为本气、中气、余气。

星运是日干相对目标支的十二长生；自坐是目标柱自己的天干相对本柱地支的十二长生。旬空按目标干支所在十日旬计算。纳音使用完整六十甲子表。

## 大运与流年

甲丙戊庚壬为阳干，乙丁己辛癸为阴干。阳年男、阴年女顺行，其余逆行。第一步大运是月柱沿六十甲子前进或后退一步，月柱自身不是第一步大运。

顺行取严格晚于出生瞬间的下一个“节”，逆行取严格早于出生瞬间的上一个“节”。换算保留整数秒与精确分数。流年区间为当年立春边界至下一年立春边界。
