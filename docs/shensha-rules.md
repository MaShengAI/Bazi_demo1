# 神煞规则目录

规则集版本：`common-shensha-2.2.0`。

本项目当前支持 55 条神煞规则。命盘、大运和流年共用这一个规则入口；规则直接使用本项目按地点、时区、真太阳时和节气边界计算出的四柱，不会在神煞模块内再次排盘。每个命中结果都包含稳定的 `code`、`rule_id` 和可读 `evidence`；同一柱上的同名神煞分别由年支和日支命中时只返回一条记录，两条依据合并保存在该记录的 `evidence` 中。
